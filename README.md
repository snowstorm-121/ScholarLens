# 研知 ScholarLens · Traceable RAG

面向 AI 论文阅读的个人科研文献助手：通过论文证据检索、本地模型问答与来源引用，帮助核对研究方法、实验设置和结论依据。

当前是开发中的个人原型，不是生产系统。正式检索与生成评测尚未完成，不承诺跨论文推理能力。

## 当前交付

本仓库仅发布当前应用 [v2/](v2/README.md)，不包含早期学习版本。

已完成：

- T1：在 Apple M5 / 16GB 上跑通两篇论文的真实本地问答和原文引用，保存失败边界。
- T2：转换 1,584 篇可用 QASPER 论文、81,549 个段落，分离正文与问答标注并保留精确证据位置。
- T3：冻结 200/300 道检索 Dev/Test 及其中 50/100 道生成子集；按用户委托完成 30 道 Dev 助手辅助语义审查（非独立人工核验），标注疑点已记录。
- T4：全量 1,584 篇论文、82,491 个 chunk 入库，接入论文范围内 BM25 / Dense / RRF Hybrid，保留定位和模型指纹；U1/U2 由助手按用户委托实现。
- 当前 V2 测试 84 项通过，覆盖数据、冻结、位置、三路检索、真实存储过滤及中断恢复。

网页已有独立全量索引，并用 train 问题跑通真实问答与引用。原 T1 两篇样例索引保留。
正式检索与生成指标尚未运行，不将烟测当作准确率，也不将辅助审查冒充独立人工金标准。

## 数据、复现与许可证

论文与标注来自 [QASPER 官方数据集](https://huggingface.co/datasets/allenai/qasper)，获取地址和固定 SHA-256 在
[数据配置](v2/configs/local.json) 中。正文、答案/证据标签分开导出，后者不作为索引输入。
原始语料、转换全文、模型、环境、数据库、索引、密钥和本机运行日志不提交 Git；通过脚本在本地准备。

应用复用成熟的开源文档问答组件，来源、固定版本与个人修改清单见 [UPSTREAM.md](v2/UPSTREAM.md)，
原有许可证和版权声明保留在 [LICENSE.txt](v2/LICENSE.txt) 及相关源码中。
QASPER 标注按数据卡的 CC BY 4.0 使用，保留论文原有权利。
本项目的贡献范围是场景适配、数据转换、证据位置与后续评测工程。
